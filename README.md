# Edge AI-Based Environmental Monitoring using STM32

## Overview
This project implements a low-cost environmental monitoring system using STM32 and NanoEdge AI for real-time anomaly detection.

## Features
- Real-time temperature monitoring
- Humidity monitoring
- Edge AI anomaly detection
- Low latency processing
- No cloud dependency

## Technologies Used
- STM32CubeIDE
- Embedded C
- STM32 HAL Drivers
- NanoEdge AI

## Hardware Used
- STM32L4S5VITX
- Environmental Sensors

## Project Structure
``` id="xrv2l2"
Core/          -> Application code
Drivers/       -> STM32 HAL drivers
NanoEdgeAI/    -> AI libraries
```
